# Sistema Bancário em Java

Projeto desenvolvido em Java com o objetivo de praticar conceitos fundamentais da linguagem e Programação Orientada a Objetos.

## Funcionalidades

- Criar contas
- Listar contas
- Realizar depósitos
- Realizar saques
- Realizar transferências
- Consultar extrato
- Histórico de operações
- Persistência das contas em arquivo
- Validação de entradas

## Conceitos utilizados

- Programação Orientada a Objetos
- Classes e objetos
- Encapsulamento
- Métodos
- Construtores
- ArrayList
- Estruturas condicionais
- Laços de repetição
- Tratamento de exceções
- Leitura e escrita de arquivos

## Estrutura

```text
src/
├── app/
│   └── Main.java
├── model/
│   └── Conta.java
└── service/
    └── Banco.java
```

## Como executar

1. Clone o repositório.
2. Abra o projeto no IntelliJ IDEA ou em outra IDE compatível com Java.
3. Execute a classe `Main`, localizada no pacote `app`.
4. Utilize o menu exibido no terminal.
